| 항목 | 내용 |

| 대상 | 강원특별자치도 시군 산불 예방 담당자 |
| 사용 상황 | 봄철 산불 예방계획을 검토하고 내부 회의 자료를 준비할 때 |

## 1. 문제와 목표

담당자가 같은 기간의 과거 산불 기록을 월별·원인별로 비교하고, 집계에 포함된 원본 행을 확인한 뒤, 조회 조건과 출처가 붙은 요약을 회의 자료에 가져갈 수 있도록 한다.

제공 CSV에서 강원 기록 218건 중 172건(78.9%)의 세부원인이 ‘기타(직접입력)’다. 원인별 집계에서 이 항목의 비중을 보여주고 상세 화면에서 기타 원문을 확인할 수 있어야 한다. 담당자가 현재 통계를 수작업으로 정리하는 빈도와 부담은 확인이 필요하다.

## 2. 사용자 흐름

1. 담당자가 대시보드를 열면 강원 전체의 2022~2025년 3~5월 집계와 사용한 CSV의 파일명·기록 범위가 보인다.
2. 같은 기간으로 고성과 강릉을 선택한다. 두 시군의 총건수, 월별 건수, 세부원인별 건수가 갱신된다.
3. 고성 4월 또는 ‘기타(직접입력)’의 집계 항목을 선택하면 해당 행의 발생일, 시군, 세부원인과 기타 원문을 확인할 수 있다.
4. ‘회의용 요약 복사’를 실행해 현재 조회 조건과 수치, 출처가 담긴 문장을 가져간다.
5. 조건에 맞는 기록이 없으면 안내 문구와 0건 요약을 제공한다. CSV를 읽거나 필수 열을 확인할 수 없으면 오류 원인을 표시하고 집계를 중단한다.

## 3. 기능 요구사항

| ID | 우선순위 | 요구사항 | 인수 기준 |
| --- | --- | --- | --- |
| FR-01 | 필수 | CSV를 읽고 필수 열을 확인한다. 시도·시군구 값 양끝의 공백을 제거해 강원 기록을 집계한다. 원본은 읽기 전용으로 사용한다. | AC-01, AC-02 |
| FR-02 | 필수 | 시작·종료 연도와 시작·종료 월, 시군 범위를 선택할 수 있게 한다. 시군은 강원 전체 또는 서로 다른 시군 한 곳·두 곳을 선택한다. 첫 화면은 CSV에 있는 연도 전체, 3~5월, 강원 전체다. 데이터 파일명과 전국 기록의 최초·최종 발생일을 표시한다. | AC-02, AC-03, AC-06, AC-08 |
| FR-03 | 필수 | 선택 기간의 총건수, 월별 막대그래프, 수치 표를 표시한다. 두 시군의 막대는 공통 축에서 비교하며 선택 월에 기록이 없으면 0을 표시한다. | AC-03, AC-06 |
| FR-04 | 필수 | 원본 세부원인별 건수를 시군별 열로 보여준다. ‘기타(직접입력)’ 비중은 해당 시군의 조건 내 총건수를 분모로 소수점 한 자리까지 표시한다. 분모가 0이면 비중은 ‘–’로 표시한다. | AC-02, AC-04, AC-06 |
| FR-05 | 필수 | 시군과 월 또는 세부원인을 선택해 원본 행을 조회한다. 상세에는 발생일, 시군, 세부원인, 기타 원문을 표시한다. | AC-05 |
| FR-06 | 필수 | 현재 필터의 기간, 지역별 총건수, 최다 기록 월과 건수, ‘기타(직접입력)’ 건수, 출처 파일명을 문장으로 만들고 클립보드에 복사할 수 있게 한다. 최다 기록 월이 여러 개면 모두 표시한다. 0건이면 해당 조건과 ‘선택 조건의 기록 0건’, 파일명을 제공한다. | AC-06, AC-07 |

월별 표와 세부원인 표, 상세 조회, 요약은 같은 기간·시군 필터 결과를 사용한다. 상세에서 월이나 원인을 선택하면 해당 집계 셀의 범위만 좁혀 보여준다. 월별 수치는 선택한 연도 범위에서 같은 달의 기록을 합산한다.

## 4. 데이터와 처리 규칙

| 항목 | 규칙 |
| --- | --- |
| 입력 | 프로젝트 루트 기준 `data/산불발생통계(20251110).csv`, CP949 CSV, 데이터 2,020행, 18열 |
| 필수 열 | `발생일시_년`, `발생일시_월`, `발생일시_일`, `발생장소_시도`, `발생장소_시군구`, `발생원인_세부원인`, `발생원인_기타` |
| 지역·집계 단위 | 시도의 공백을 제거해 `강원`인 행을 선택한다. 시군구는 양끝 공백을 제거한다. 시군 선택지는 전체 강원 기록에 나타난 17곳에서 제공하며 날짜 필터가 바뀌어도 유지한다. 한 행을 기록 1건으로 집계하고, 날짜·시군이 같아도 합치지 않는다. |
| 원인 처리 | `발생원인_세부원인`의 원본 분류를 사용한다. `발생원인_기타`의 ‘조사중’, ‘미상’, 추정 문구 등을 원문으로 표시한다. `발생원인_구분`은 코드 정의가 확인될 때까지 집계에 사용하지 않는다. |
| 기간 처리 | 시작·종료 연도와 월을 각각 포함한다. 예를 들어 2022~2025년과 3~5월을 고르면 4개 연도 각각의 3~5월을 집계한다. 시작 값이 종료 값보다 늦으면 입력을 바로잡도록 안내한다. |
| 기간 표기 | 원본 전국 기록 범위는 2022-01-01~2025-09-11이고, 강원 기록 범위는 2022-01-03~2025-08-28이다. 파일의 발생일 범위는 수록 완전성을 보장하지 않으므로 화면과 요약에서 ‘기록 건수’로 표기한다. |
| 오류·빈 결과 | 파일 누락, 디코딩 실패, 필수 열 누락은 오류로 안내한다. 유효한 필터에서 일치 행이 없으면 조회 조건과 0건 상태를 표시한다. |

## 5. 첫 구현 범위와 후속 범위

- 첫 구현은 로컬 CSV 읽기, 기간·시군 필터, 월별·세부원인별 비교, 원본 상세 조회, 회의용 문장 복사까지다. 기획서의 기술 제안은 Python과 Streamlit을 이용한 한 화면 웹앱이다. 앱 실행과 관련된 구현 파일은 `app/`에 둔다.
- 담당자 수요가 확인되면 AI 문장 다듬기를 검토한다. 기간 비교는 연월별 수록 범위, 지도는 행정구역 코드와 경계 자료, 피해면적 지표는 원본 단위 확인이 선행되어야 한다. 실시간 감시·예측과 순찰 인력 자동 배치는 후속 과제로 둔다.

### 현장 사용성 평가

담당자 2~3명이 기존 방식과 시제품으로 같은 조건의 시군 비교표를 작성한다. 작성 시간, 수치·출처 오류, 원문 확인 여부를 기록한다. 기획서의 잠정 목표는 작성 시간 중앙값 30% 단축과 수치·출처 오류 0건이다. 실제 업무 부담과 목표 달성 여부는 검증 후 판단한다.

## 7. 근거와 미결 사항

- 기획 범위와 우선순위는 `docs/SERVICE_PLAN.md`를 따랐다. 원본 파일에서 필드명과 강원 218건, 기타 172건, 강릉 25건, 봄철 시군 비교값을 확인했다.
- 첫 화면은 기획서의 봄철 시나리오를 적용하고, 연도는 CSV에 기록된 전체 연도 범위로 정했다. 시군 선택지는 원본의 강원 기록에 나타난 지역을 기준으로 구성한다.
- 원본의 공식 배포 이력과 연월별 수록 완전성, 시군 전체 공식 목록, 피해면적 단위, 담당자의 실제 작업 방식과 보고 양식은 확인이 필요하다.
